- URL 단축 서비스를 설계해보세요. (채번, 리다이렉트 latency, 통계)
- 정기 구독 결제 시스템을 설계해보세요. (자동 갱신, 실패 재시도, 해지)
- 검색 자동완성을 설계해보세요.
- 글로벌 서비스의 콘텐츠 배포 파이프라인을 설계해보세요. (국가별 노출 정책, 번역본 관리)
- A/B 테스트 플랫폼을 설계해보세요. (버킷팅, 지표 수집)
- SNS 피드/타임라인을 설계해보세요. (팔로우 관계, push vs pull 팬아웃, 유명인 문제)
- 실시간 채팅(1:1, 그룹)을 설계해보세요. (메시지 순서와 ID, 읽음 표시, 오프라인 푸시, 저장소 선택)

### 알면 좋은 +α

- 이미지 업로드부터 썸네일 생성·서빙까지의 파이프라인을 설계해보세요.
- 한 계정의 여러 기기 동시 이용을 제한하는 시스템을 설계해보세요.
- 운영 중인 수억 건 테이블을 무중단으로 새 저장소로 이전하는 과정을 설계해보세요.

> 시스템 설계 답변 프레임: 요구사항 명확화(기능/비기능, 규모 추정) → 대략적 설계(API, 데이터 모델) → 핵심 컴포넌트 심화 → 병목/장애 시나리오 → 트레이드오프 정리

## 26. 인증 / 인가 / 세션 (이력 기반 심화)

> 이력서에 IAM·인증 도메인 경력이 있으면 면접관은 반드시 이 영역을 파고든다. 가장 깊게 답해야 하는 홈그라운드이자, 콘텐츠 플랫폼의 계정·세션·기기 제한 기능과 직결되는 영역이다.

### 기본 ⭐

- 인가 모델 RBAC과 ABAC의 차이는? 조직 계층(회사-부서-팀)이 있는 서비스의 권한 설계는 어떻게 하나요?

### 중급 ⭐⭐

- 동시 로그인 제한(기기 수 제한, 중복 로그인 차단)을 어떻게 구현하나요? 정확성과 사용자 경험의 균형은 어디서 잡나요?
- "로그아웃하면 토큰이 즉시 무효화되어야 한다"는 요구를 JWT 기반 시스템에서 어떻게 구현하나요? 그렇게 하고 나면 JWT의 장점은 얼마나 남나요?
- 멀티테넌트 서비스에서 테넌트 간 데이터 격리 방식들(DB 분리, 스키마 분리, 로우 레벨 격리)과 선택 기준은?

- 웹 클라이언트에서 토큰을 어디에 저장해야 하나요? (httpOnly 쿠키 vs localStorage) XSS/CSRF 관점의 트레이드오프는?

### 고난이도 ⭐⭐⭐

- 수만 개 테넌트가 쓰는 B2B 서비스에서 고객사의 대규모 조직 개편(수천 명 입사/퇴사/부서 이동)을 동기화하는 시스템을 설계해보세요. (SCIM, 배치 vs 이벤트, 부분 실패 복구)

- 권한 변경(퇴사, 권한 회수)이 이미 발급된 세션/토큰에 반영되기까지의 지연을 어떻게 다루나요? 즉시 반영이 꼭 필요한 지점과 그 비용은?

### 알면 좋은 +α

- OAuth의 client credentials, device code 등 authorization code 외의 grant는 각각 어떤 상황을 위한 것인가요?
- 로그인에 크리덴셜 스터핑이 들어올 때 계정 잠금 정책의 딜레마(공격자가 잠금을 역이용한 DoS)는 어떻게 푸나요?
- 인증/인가 감사 로그는 무엇을 남겨야 하고, 일반 로그와 요구 수준이 어떻게 다른가요?
- 패스키(WebAuthn) 같은 패스워드리스 인증에서 백엔드가 관리해야 하는 것들은? 비밀번호 방식 대비 무엇이 사라지고 무엇이 새로 생기나요?

## 준비 팁

1. **모든 "고난이도" 질문은 정답보다 사고 과정**을 본다 — 트레이드오프를 양쪽 다 말하고, 본인의 선택 기준을 명확히.
2. **경험 질문은 STAR 구조**(상황-과제-행동-결과)로, 반드시 수치(TPS, latency, 절감률)를 준비.
3. 공고 도메인(콘텐츠, 결제, 글로벌) 특성상 **멱등성, 정합성, 스파이크 트래픽** 관련 질문은 거의 확실히 나온다 — 10, 5, 7장을 집중 준비.
4. "모르는 것"을 물어보면 아는 지점까지 설명하고 추론하는 모습을 보여줄 것 — 침묵이나 즉답 포기가 최악.
5. 꼬리 질문에 대비해 본인이 말한 모든 키워드는 한 단계 더 깊이 설명할 수 있어야 한다.
6. **답변의 3단계 등급을 의식하라** — ① 안다(개념 설명) ② 겪었다(증상·삽질·트레이드오프) ③ 체계를 만들었다(재발 방지를 팀 자산으로). 공고 연차보다 높은 잣대가 적용될 수 있으므로, 주력 3~4개
   주제는 반드시 ③단계 답을 준비할 것. (상세: rationale 문서 25장)
