# 23. 빌드 / CI·CD / 형상관리

## 기본 ⭐

- Git 브랜치 전략(Git Flow, GitHub Flow, trunk-based)을 비교하고, 어떤 기준으로 선택하나요?
- CI 파이프라인에는 어떤 검증 단계를 어떤 순서로 배치하나요? 그 순서의 근거는?
- Gradle의 `api`와 `implementation` 의존성의 차이는? 멀티모듈 프로젝트에서 왜 중요한가요?

## 중급 ⭐⭐

- 빌드/테스트 시간이 20분을 넘기 시작했습니다. 어떤 순서로 개선하나요?
- 배포를 롤백해야 하는데 이번 배포에 DB 마이그레이션이 포함되어 있었습니다. 무엇이 문제이고, 애초에 어떻게 대비했어야 하나요? (expand-contract)
- Spring Boot 메이저 버전 업그레이드(2→3)를 운영 중인 서비스에서 어떤 절차로 진행하나요?

## 고난이도 ⭐⭐⭐

- 모노레포와 멀티레포의 트레이드오프를 비교하고, 어떤 상황에서 무엇을 선택하겠습니까?
