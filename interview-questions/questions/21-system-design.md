# 21. 시스템 설계 (화이트보드 대비)

- 웹툰 플랫폼의 "회차 열람" 시스템을 설계해보세요. (열람권 검증, 이미지 서빙, 열람 기록)
- 실시간 인기 순위(최근 1시간 조회수 기준 Top 100)를 설계해보세요.
- 댓글 시스템을 설계해보세요. (대댓글, 좋아요, 베스트 댓글, 신고/블라인드)
- 선착순 쿠폰 발급 시스템을 설계해보세요. (10만 장, 초당 수만 요청)
- 알림 시스템을 설계해보세요. (신작 알림 — 관심 웹툰 등록자 수백만 명에게 발송)
- URL 단축 서비스를 설계해보세요. (채번, 리다이렉트 latency, 통계)
- 정기 구독 결제 시스템을 설계해보세요. (자동 갱신, 실패 재시도, 해지)
- 검색 자동완성을 설계해보세요.
- 글로벌 서비스의 콘텐츠 배포 파이프라인을 설계해보세요. (국가별 노출 정책, 번역본 관리)
- A/B 테스트 플랫폼을 설계해보세요. (버킷팅, 지표 수집)
- SNS 피드/타임라인을 설계해보세요. (팔로우 관계, push vs pull 팬아웃, 유명인 문제)
- 실시간 채팅(1:1, 그룹)을 설계해보세요. (메시지 순서와 ID, 읽음 표시, 오프라인 푸시, 저장소 선택)

## 알면 좋은 +α

- 이미지 업로드부터 썸네일 생성·서빙까지의 파이프라인을 설계해보세요.
- 한 계정의 여러 기기 동시 이용을 제한하는 시스템을 설계해보세요.
- 운영 중인 수억 건 테이블을 무중단으로 새 저장소로 이전하는 과정을 설계해보세요.

> 시스템 설계 답변 프레임: 요구사항 명확화(기능/비기능, 규모 추정) → 대략적 설계(API, 데이터 모델) → 핵심 컴포넌트 심화 → 병목/장애 시나리오 → 트레이드오프 정리
