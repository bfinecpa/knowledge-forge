# knowledge-web

`knowledge/`의 학습 문서를 **웹에서 읽기 쉽고 오래 기억되도록** 다시 만든 HTML 버전.
폴더 구조와 파일이 `knowledge/`와 1:1로 대응한다.

```
knowledge/01-java-kotlin/g1gc-vs-zgc.md
      ↓
knowledge-web/01-java-kotlin/g1gc-vs-zgc.html
```

## 보는 법

빌드 결과물은 **정적 HTML**이라 서버가 필요 없다. 파일을 그냥 열면 된다.

```bash
open interview-questions/knowledge-web/index.html
```

`index.html`이 전체 대시보드다. 26개 카테고리, 문서 카드, 진도 통계, 검색이 여기 있다.

## 다시 빌드하기

`knowledge/`에 문서를 추가하거나 고친 뒤:

```bash
cd interview-questions/knowledge-web
node build.mjs
```

원본을 읽어 HTML 전체를 다시 만든다. 빈 카테고리 디렉토리도 함께 생성해 구조를 맞춘다.
**HTML은 직접 고치지 말 것** — 다음 빌드에서 덮어쓰인다. 내용은 `knowledge/`의 `.md`를,
디자인·동작은 `assets/`와 `build.mjs`를 고친다.

## 기억에 남기기 위한 장치

| 기능 | 설명 |
|---|---|
| **셀프테스트 모드** (`s`) | 핵심 관전 포인트·한 줄 요약을 흐리게 가리고 꼬리질문 답을 접는다. 먼저 떠올려본 뒤 확인하는 인출 연습(retrieval practice)용 |
| **꼬리질문 플래시카드** | 원문의 꼬리질문·부록 Q&A를 질문만 보이는 카드로 변환. 눌러야 답이 열린다 |
| **섹션 진도 체크** | 섹션마다 ✓ 체크. 목차·문서 카드·대시보드 통계에 반영되고 브라우저에 저장된다 |
| **복습 목록** (`b`) | 다시 볼 문서를 🔖로 표시. 대시보드에서 모아 본다 |
| **Before / After 나란히** | 원문의 `// Before` `// After` 코드를 좌우 2단(❌ 빨강 / ✅ 초록)으로 분리 |
| **카테고리별 색상** | 26개 카테고리에 각각 다른 색을 배정 — "Spring은 초록"처럼 위치 기억을 돕는다 |
| **자동 상호참조** | 본문의 `` `문서명.md` `` 를 해당 페이지 링크(↗)로 자동 연결 |

## 단축키

| 키 | 동작 |
|---|---|
| `j` / `k` | 다음 / 이전 섹션 |
| `s` | 셀프테스트 모드 |
| `b` | 복습 목록 표시 |
| `/` 또는 `⌘K` | 전체 문서 검색 |
| `t` | 다크/라이트 테마 |
| `h` | 대시보드로 |
| `Esc` | 검색·목차 닫기 |

## 구성

| 경로 | 용도 |
|---|---|
| `build.mjs` | 빌더. 마크다운 파서 + 문법 하이라이터 + 학습용 변환. 외부 의존성 없음 |
| `assets/style.css` | 디자인 시스템 (라이트/다크, 카테고리 색상, 인쇄 스타일) |
| `assets/app.js` | 인터랙션 (진도·검색·셀프테스트·목차 추적) |
| `assets/data.js` | 빌드 시 생성되는 문서 색인 (검색·통계용) |
| `index.html` | 대시보드 |
| `<카테고리>/*.html` | 문서 페이지 |
| `README.html` | `knowledge/README.md`(카테고리 규약)의 웹 버전. 이 파일(`README.md`)과는 별개다 |

진도와 복습 목록은 브라우저 `localStorage`에 저장된다. 기기·브라우저 간 동기화는 되지 않으며,
대시보드의 **진도 초기화** 버튼으로 지울 수 있다.
